================================================================
  QUILL PATCH — How to add the Rich Post tab to create_post.php
================================================================

In create_post.php, make THREE changes:

────────────────────────────────────────────────────────────────
CHANGE 1 — Add Quill CDN links in the <head> section
           (paste right before the closing </style> tag)
────────────────────────────────────────────────────────────────

  <link href="https://cdn.quilljs.com/1.3.7/quill.snow.css" rel="stylesheet">

  /* Add inside your <style> block: */
  .ql-toolbar.ql-snow { border-radius:0; border-color:rgba(255,255,255,.12) !important; background:rgba(255,255,255,.05); }
  .ql-container.ql-snow { border-color:rgba(255,255,255,.12) !important; background:transparent; min-height:160px; }
  .ql-editor { color:#f0eff5 !important; font-size:15px !important; line-height:1.8 !important; min-height:160px; }
  .ql-editor.ql-blank::before { color:#9b9ab0 !important; font-style:normal !important; }
  .ql-stroke { stroke:#9b9ab0 !important; }
  .ql-fill  { fill:#9b9ab0 !important; }
  .ql-picker-label { color:#9b9ab0 !important; }
  #quill-error { color:var(--danger); font-size:13px; margin:8px 16px; display:none; }


────────────────────────────────────────────────────────────────
CHANGE 2 — Add the Rich Post tab button
           Find the post-type-tabs div and add this button:
────────────────────────────────────────────────────────────────

  <button type="button" class="post-type-tab" onclick="switchPostTab('rich',this)"> Rich Post</button>


────────────────────────────────────────────────────────────────
CHANGE 3 — Add the Rich Post pane
           Paste this AFTER the <!-- DOC tab --> closing </div>
           and BEFORE the post-footer div:
────────────────────────────────────────────────────────────────

  <!-- RICH tab -->
  <div class="post-type-pane" id="pane-rich">
    <div id="quill-editor" style="min-height:160px;"></div>
    <input type="hidden" name="content" id="quill-content">
    <div id="quill-error"></div>
  </div>


────────────────────────────────────────────────────────────────
CHANGE 4 — Load Quill scripts before closing </body>
────────────────────────────────────────────────────────────────

  <script src="https://cdn.quilljs.com/1.3.7/quill.min.js"></script>
  <script src="QuillEditor/quill_toolbar.js"></script>
  <script src="QuillEditor/quill_editor.js"></script>
  <script src="QuillEditor/quill_save.js"></script>


────────────────────────────────────────────────────────────────
CHANGE 5 — In switchPostTab() JS function, add this line
           so the editor only inits when Rich tab is opened:
────────────────────────────────────────────────────────────────

  function switchPostTab(name, btn) {
    document.querySelectorAll('.post-type-pane').forEach(p => p.classList.remove('active'));
    document.querySelectorAll('.post-type-tab').forEach(b => b.classList.remove('active'));
    document.getElementById('pane-'+name).classList.add('active');
    btn.classList.add('active');
    document.getElementById('activeTabInput').value = name;

    // ADD THIS — re-style Quill when tab becomes visible
    if (name === 'rich' && quillInstance) {
      quillInstance.focus();
    }
  }

================================================================
  That's it! The QuillEditor/ folder handles all the logic.
  post.php already detects HTML content and renders it richly.
================================================================
